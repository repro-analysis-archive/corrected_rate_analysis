# Data access and expected layout

No patient-level source data and no patient identifiers are redistributed in this repository. The analysis is
reproduced from the public datasets below, placed under `external_data/` (or any directory named in
`JIIM_DATA_ROOT`).

## Sources

| data | repository | identifier | access |
|---|---|---|---|
| I-SPY2 TRIAL pretreatment DCE-MRI | The Cancer Imaging Archive (TCIA) | https://doi.org/10.7937/TCIA.D8Z0-9T85 | per the TCIA data-usage policy of the collection |
| MAMA-MIA: curated images, expert tumour segmentations and harmonized clinical variables (`clinical_and_imaging_info.xlsx`) | Synapse | https://doi.org/10.7303/syn60868042 | Synapse account and acceptance of the dataset terms of use |

The analysis used the MAMA-MIA curation of the I-SPY2 cohort: its harmonized clinical workbook, its expert
segmentations and its preprocessed images.

```

    radiomics_her2neg_binCount64_20260725.csv
    radiomics_her2pos_binCount64_20260725.csv
    biomedclip_her2neg_reextract_20260725.csv
    biomedclip_her2pos_reextract_20260725.csv
    raddino_her2neg_reextract_cls_usefast_20260725.csv
    raddino_her2pos_reextract_cls_usefast_20260725.csv
  archive/                                optional: feature matrices of the original study, used only by the verification scripts of the feature round
```

The 980 patients (739 HER2-negative, 241 HER2-positive) are defined by the workbook filter below; the scripts derive
the lists themselves (`src/features/cohort_ids.py`, `src/rate_analysis/r4_stageA.py`), and their digests are in
`splits/SPLIT_DIGESTS.json`. The regenerated feature matrices can be checked against the sha256 values in
`checksums/INPUT_PROVENANCE.txt`.

## Derivation of the analysis variables (as implemented in `src/rate_analysis/r4_stageA.py`, function `load`)

| variable | derivation from `clinical_and_imaging_info.xlsx` |
|---|---|
| cohort rows | `dataset == "ISPY2"`, `her2 == 0` (HER2-negative) or `her2 == 1` (HER2-positive), non-missing `pcr`; workbook row order defines the analysis-frame order |
| outcome `Y` | `pcr` (pathologic complete response) |
| treatment `T` | `1` if `nac_agent` differs from the cohort's control arm (`"Paclitaxel"` for HER2-negative; `"Paclitaxel + Trastuzumab"` for HER2-positive), else `0` |
| clinical effect modifiers | `age` (median-imputed within cohort), label-encoded `tumor_subtype`, `ethnicity`, `bmi_group`, `menopause` (missing categories coded `unknown`) |
| evaluation covariates Z (imaging-free) | age (+ missingness indicator), `hr`, `mammaprint`, one-hot `ethnicity`, `bmi_group`, `menopause` (whitespace variants of "pre" merged), enrolment-epoch indicators; see `results/rate_primary/Z_provenance.json` |
| enrolment epoch | regenerated by `src/rate_analysis/derive_epochs.py` from `acquisition_date` and `nac_agent` (rule in `config/epoch_canonical_mapping.json` and `splits/README.md`) |

The released per-patient derived files carry positional row labels rather than identifiers; `derived_data/README.md`
explains how they align with a regenerated run.
