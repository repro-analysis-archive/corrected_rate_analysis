# Figure-source data

One hash-guarded JSON per figure plus one MATLAB `.mat` file, produced by `src/figures/freeze_figure_data.py`
from the released results (values are selected and reformatted, never recomputed).

| file | figure | source results |
|---|---|---|
| `Fig1_data.json` | Fig. 1, analytic framework (cohort counts, split, four questions) | cohort and split counts from `priorities_provenance.json` and `rate_her2pos_not_estimated.json` |
| `Fig2_data.json` | Fig. 2, Q1 configuration-specific RATE/AUTOC with 95 % CI | `results/rate_primary/rate_q1_primary.json` |
| `Fig3_data.json` | Fig. 3, Q2 paired estimates (A) and ΔRATE with sensitivities (B) | `rate_q2_primary.json`, `rate_q2_sensitivities.json` |
| `Fig4_data.json` | Fig. 4, Q3 change in RATE (same-sample − opposite-half), H1 / H2 / pooled | `results/rate_q3/rate_q3.json` |
| `Fig5_data.json` | Fig. 5, Q4 regime schematic, half-specific B − A, pooled P / S / P×S | `results/rate_q4/rate_q4_regimes.json`, `rate_q4_contrasts.json` |
| `fig_data_r7.mat` | numeric arrays and labels read by `src/figures/make_Fig*.m` | the five JSON files |
| `FIGURE_DATA_SHA256.txt` | sha256 of the files above and of their upstream sources | |

The `provenance` block of each JSON records, for every upstream file, its sha256 in the frozen record and the
verification performed; the paths in that block were rewritten from local absolute paths to repository-relative
paths for this release. Two upstream entries (the frozen split table and the frozen epoch table) refer to files
that are not distributed because they carry patient identifiers; they are regenerated by the released code
(`splits/README.md`), and the released result files are byte-identical to the record, so the remaining hashes
verify directly. `fig_data_r7.mat` is byte-identical to the record.

Two descriptive label strings in the JSON metadata use the working term "honest" for regime A
(`Fig1_data.json`: question Q3; `Fig4_data.json`: `x_label`); the final figures and the manuscript use
"opposite-half" for the same regime. Plotted values are unaffected.
