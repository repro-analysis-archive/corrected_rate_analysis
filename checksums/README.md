# Checksums and provenance

| file | content |
|---|---|
| `SHA256SUMS.txt` | sha256 of every file in this release (`bash scripts/verify_checksums.sh` verifies them) |
| `INPUT_PROVENANCE.txt` | sha256 of every frozen input the corrected analysis consumed: the clinical workbook, the epoch table (regenerated by `src/rate_analysis/derive_epochs.py`), the six feature matrices and the frozen loader module; local paths replaced by repository-relative labels |
| `original_frozen_manifests/` | the manifests of the frozen feature and epoch sets of the development record (`FROZEN_R2B`, `FROZEN_R2C`, `FROZEN_EPOCH`); the manifests of the three analysis rounds are `results/*/ORIGINAL_SHA256SUMS.txt` |

The frozen record also holds a per-file sha256 manifest of the source images and masks that entered the feature
extraction; it is not distributed because its file paths carry patient identifiers.

Frozen-record hashes apply to the original files. Where a released file differs from its original (row-labelled
data files, path-edited scripts, path-rewritten records), `docs/CODE_MODIFICATIONS.md` gives both hashes. The
digests of the split, partition, epoch and cohort sets are in `splits/SPLIT_DIGESTS.json`.
